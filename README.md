## 📖 Overview

**AI Interview Evaluation System** is a full-stack AI-powered platform designed to help students, freshers, and job seekers prepare for technical and HR interviews.

Instead of relying on generic interview questions, the system creates a personalized interview experience using:

- 📄 Candidate resume
- 💼 Target job description
- 🎯 Target role
- 👨‍💻 Experience level
- 🗣️ Interview type
- ⚡ Difficulty level

Google Gemini analyzes the provided information and generates relevant interview questions. Candidate answers are then evaluated using AI to provide structured feedback and performance insights.

---

## 🎯 Problem Statement

Traditional interview preparation platforms often provide static or generic questions that do not reflect an individual's actual skills, projects, experience, or target role.

This project addresses that limitation by creating an **AI-driven personalized interview workflow** that adapts questions and evaluation to each candidate.

### The system aims to:

- Analyze candidate resumes
- Understand target job requirements
- Generate personalized interview questions
- Evaluate candidate responses
- Identify strengths and weaknesses
- Provide actionable improvement feedback

- Projects
